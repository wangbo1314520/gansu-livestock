## 2. 技术选型与理由

| 层 | 技术 | 版本 | 选型理由 |
|---|---|---|---|
| 后端框架 | Flask | 3.1.x | 轻量、生态成熟，毕设答辩讲解成本低 |
| ORM | SQLAlchemy | 2.1.x | Python 标准 ORM，模型与建表 SQL 一一对应 |
| 数据库 | MySQL | 8.x | 已有 Navicat 使用习惯；InnoDB + utf8mb4 |
| 认证 | PyJWT + bcrypt | — | 无状态 token，家用版 7 天有效期少登录 |
| 定时任务 | APScheduler | 3.11 | 进程内调度，不依赖额外中间件 |
| 数据处理 | pandas / numpy | 3.0.x / 2.5.x | 清洗、插值、相关性计算 |
| 时序建模 | statsmodels | 0.15 | ARIMA/SARIMAX 标准实现，论文引用多 |
| 机器学习 | scikit-learn | 1.9 | 备用（异常检测、后续 LSTM 对比基线） |
| 爬虫 | requests + BeautifulSoup + lxml | — | 政府站点静态页为主，无需重型框架 |
| 学校版前端 | Vue3 + Element Plus + ECharts | — | 桌面端组件全、图表能力强 |
| 家用版前端 | Vue3 + Vant + ECharts | — | 移动端体验好、组件贴手机交互习惯 |
| 构建工具 | Vite | 5.x | 启动快，两个前端共用一套心智 |

## 3. 关键设计决策

### 3.1 一套后端、两个前端
后端通过 `config.MODE`（环境变量 `APP_MODE=school|home`）控制功能开关：
家用版专属接口（cost/advice/farm/ledger）在 school 模式直接返回 403，
避免维护两套后端。数据层、预测层完全共用。

### 3.2 价格数据单表设计
牛羊价格与饲料价格共用 `price_data` 表，以 `price_category.type`
区分 livestock / feed。好处：趋势查询、同比环比、预测管道只写一套；
饲料价作为 ARIMAX 外生变量取数路径与主序列一致。

### 3.3 预测管道分层
- `predict/`（纯算法包，不依赖 Flask）：preprocess → arima/arimax → evaluate
- `backend/service/predict_service.py`（业务组装）：取数 → 调模型 → 落库
- 算法包可独立单测（本次初始化已用合成数据验证：MAPE≈2%，评级优秀）

### 3.4 单位约定（易错点）
- 价格库统一 **元/斤**（与政府监测口径一致）
- 体重、日增重、日饲料量统一 **kg**
- 计算时按 1kg = 2斤 显式换算，`cost_service` 集中处理

### 3.5 外网访问（家用版部署）
家里主机跑后端 + 前端静态文件，手机经 Tailscale 访问，无需公网 IP、
不暴露公网，满足"完全私有"要求。

## 4. 目录结构

```text
gansu-livestock/
├── backend/               # Flask 后端
│   ├── app.py             # 入口（create_app 工厂）
│   ├── config.py          # MODE 开关 + DB/JWT 配置
│   ├── requirements.txt   # 依赖清单（pip freeze 生成）
│   ├── api/               # 路由层：auth/base/price/feed/predict/
│   │                      #   analysis/alert/cost/advice/farm/ledger/admin
│   ├── service/           # 业务层（9 个 service）
│   ├── model/             # ORM：17 张表映射
│   ├── utils/             # response/auth(JWT+bcrypt)/logger/scheduler
│   └── sql/               # init.sql + init_data.sql
├── frontend-school/       # 学校版（Element Plus，端口 5173）
├── frontend-home/         # 家用版（Vant，端口 5174）
├── spider/                # gov_spider / feed_spider / clean / import_db
├── predict/               # preprocess / arima / arimax / predictor / evaluate
├── data/                  # raw/（爬虫原始） clean/（清洗后） backup/（备份）
└── docs/                  # 全部文档
```

## 5. 已知风险与对策

| 风险 | 对策 |
|---|---|
| 政府站点改版导致爬虫失效 | 爬虫框架统一输出结构，逐源独立 try/except，单源失败不影响整体 |
| 历史数据不足 30 条无法预测 | run_predict 显式报错提示；先手工导入历史数据（/api/price/import） |
| Python 3.14 生态兼容 | 全部依赖已实测安装并通过导入验证；两处 API 变更已修复（见 error.log） |
| 家人不会用 | 家用版首页只放四个数字 + 快捷入口；建议页面用大白话 |
