## 1. 项目初衷（最重要）

让家人看到行情怎么样、能不能卖、以后价格会怎么样。自动搜索网上的数据联系起来。

具体拆解为三个核心问题：

- **现在行情怎么样？** —— 今天活牛、活羊、牛肉、羊肉、饲料什么价
- **能不能卖？** —— 现在卖能赚多少，再养一段时间能赚多少
- **以后价格会怎么样？** —— 用历史数据和网络数据预测未来趋势

所有功能设计都围绕这三个问题展开，不做花哨无用的东西。

## 7. 成本计算逻辑（核心）

### 7.1 日饲料成本

```python
def calc_daily_feed_cost(feed_detail, daily_feed_amount, feed_prices):
    """
    feed_detail: {"玉米":0.6,"豆粕":0.2,"麸皮":0.1,"苜蓿草":0.1}
    daily_feed_amount: 日饲料量 kg
    feed_prices: {"玉米":1.25,"豆粕":2.0,"麸皮":0.9,"苜蓿草":1.5}
    """
    cost = 0
    for feed, ratio in feed_detail.items():
        cost += ratio * daily_feed_amount * feed_prices[feed]
    return cost
```

### 7.2 出栏利润

```python
def calc_profit(weight, current_price, total_cost):
    """
    weight: 当前体重 kg（换算成斤）
    current_price: 当前售价 元/斤
    total_cost: 累计成本
    """
    revenue = weight * 2 * current_price  # kg转斤
    return revenue - total_cost
```

### 7.3 盈亏平衡价

```python
def calc_breakeven(total_cost, weight):
    return total_cost / (weight * 2)
```

### 7.4 压栏决策

```python
def calc_delay_profit(weight, daily_gain, daily_feed_cost,
                       daily_other_cost, current_price,
                       days, predicted_price):
    """
    压栏N天后的利润
    """
    future_weight = weight + daily_gain * days
    future_cost = (daily_feed_cost + daily_other_cost) * days
    future_revenue = future_weight * 2 * predicted_price
    return future_revenue - future_cost
```

### 8.1 数据预处理

1. 按 category_id + region_id 分组
2. 按日期排序，缺失值插值
3. 异常值检测（IQR）
4. 平稳性检验（ADF）
5. 差分（如需）

### 8.2 ARIMA 模型

用于牛羊价格基础预测：

```python
from statsmodels.tsa.arima.model import ARIMA
model = ARIMA(series, order=(p, d, q))
result = model.fit()
forecast = result.forecast(steps=30)
```

### 8.3 ARIMAX 模型（含饲料变量）

把饲料价格作为外生变量，提高精度：

```python
from statsmodels.tsa.statespace.sarimax import SARIMAX
model = SARIMAX(
    livestock_price,
    exog=feed_price,
    order=(p, d, q),
    seasonal_order=(P, D, Q, s)
)
```

### 8.4 评价指标

| 指标 | 公式 | 标准 |
|---|---|---|
| MAE | mean(\|y - ŷ\|) | 越小越好 |
| RMSE | sqrt(mean((y - ŷ)²)) | 越小越好 |
| MAPE | mean(\|(y - ŷ)/y\|) × 100% | <10%优秀，<20%良好 |

### 8.5 出栏建议规则

```text
输入：当前价 P，成本线 C，预测价 P_f
规则：
  if P > C and P_f < P:     建议出栏
  if P < C and P_f > P:     可压栏
  if P < C and P_f < P:     尽快出栏止损
  if P > C and P_f > P:     可继续观察
```
