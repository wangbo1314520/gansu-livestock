# 记录导入说明（家庭记录 → 系统的过渡方案）

> 现状：家人先用 Excel 记，每月由你（管理员）手动导入系统。
> 后续版本会做"Excel 一键上传导入"功能，现在先把流程跑起来。

## 一、家人怎么记

1. 把 `data/家庭牧场记录模板.xlsx` 发到家庭群，让爸妈**另存一份**到自己手机/电脑
2. 三个表分工：
   - **卖牛羊记录**：每卖一批记一行（卖了就记，当天记）
   - **买饲料记录**：每买一次饲料记一行
   - **贩子报价记录**：贩子来问价/报价时随手记（这个最值钱——多个人报价能看出行情）
3. 只要求两点：**日期格式照示例写**（2026-10-01）、**别改列名**

## 二、每月怎么导入（你操作）

1. 收到家人的 Excel 后，先检查：日期格式、数字列没混入文字
2. 手动导入入口（二选一）：
   - **卖牛羊** → 家用版"账本"页逐笔录入（收入：金额 = 数量×体重×2×单价）
     或调 `POST /api/ledger/add`（type=income，category=卖牛/卖羊）
   - **贩子报价** → 调 `POST /api/price/add`（source=dealer，source_detail=报价人）
     这批数据最有价值：系统会以 source='dealer' 单独标记，与政府周报区分
3. 导入后在系统"价格查询"里按来源=dealer 过滤核对一遍

## 三、字段对照（Excel → 系统接口）

| Excel 列 | 系统字段 | 说明 |
|----------|---------|------|
| 日期 | record_date / trade_date | YYYY-MM-DD |
| 品种+阶段 | breed_id | 对照 /api/base/breeds（如 黄牛-育肥） |
| 单价(元/斤) | price | 贩子报价用元/斤口径，与系统一致 |
| 报价人/买家 | source_detail | 存来源明细 |

## 四、频次建议

- 家人：随手记（报价尤其要及时，隔天就忘）
- 你：每月 1 号导一次，顺手看月报（`gen_monthly_report.py`）
