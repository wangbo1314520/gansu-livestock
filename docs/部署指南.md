# 部署指南

> 更新：2026-10-10（第六轮部署预演，未实际执行 docker build）

## 一、环境要求

| 组件 | 版本 | 说明 |
|------|------|------|
| Docker | 20.10+ | 含 compose v2 |
| Node | 20+ | 仅构建前端时需要（可本地构建后只上传 dist） |
| 内存 | 2GB+ | MySQL + Flask + statsmodels |
| 端口 | 80 / 3307 / 5000 | nginx / MySQL（宿主映射）/ 后端（可不对公网开） |

## 二、一键启动

```bash
# 1. 准备前端产物（已构建则跳过：deploy/html/ 下已就位）
cd frontend-school && npm run build && cd ..
cd frontend-home && npm run build && cd ..
mkdir -p deploy/html/school deploy/html/home
cp -r frontend-school/dist/* deploy/html/school/
cp -r frontend-home/dist/* deploy/html/home/

# 2. 启动（DB_PASSWORD 只从环境变量传，不写入任何文件）
export DB_PASSWORD=你的密码
docker compose up -d

# 3. 初始化数据库（compose 已自动导入 init.sql / init_data.sql；如需手动）
docker exec -i gl_mysql mysql -uroot -p$DB_PASSWORD gansu_livestock < backend/sql/init.sql

# 4. 验证
curl http://127.0.0.1/api/health        # {"code":200,...}
```

- 学校版：http://服务器IP/
- 家用版：http://服务器IP/home/
- 切换家用模式：`APP_MODE=home docker compose up -d backend`

## 三、镜像说明

- 基础镜像 `python:3.14-slim`（与开发 venv 3.14 一致）；若标签不可用改 `python:3.12-slim`，
  依赖均兼容 3.12+，需同步修改 backend/Dockerfile 第一行
- MySQL 8.0 挂载 `./data/mysql`，删除容器不丢数据；初始化 SQL 经 docker-entrypoint-initdb.d 自动执行

## 四、Tailscale 配置（家用版远程访问）

家用版供家人手机使用，推荐 Tailscale 内网穿透（免公网 IP/端口暴露）：

```bash
# 服务器端
curl -fsSL https://tailscale.com/install.sh | sh
tailscale up
tailscale ip -4        # 记下 100.x.x.x

# 家人手机：安装 Tailscale App → 登录同一账号 → 访问
#   http://100.x.x.x/home/
```

- 无需任何端口转发；离线在家时可改用局域网 IP
- 家用版登录账号由管理员在学校版"后台管理"创建（家用账号）

## 五、常见问题

| 问题 | 处理 |
|------|------|
| 预测接口慢/超时 | 首次加载 statsmodels 约 5 秒；nginx 已设 120s 读超时 |
| MySQL 容器起不来 | 检查 3307 是否被占用，或 data/mysql 有旧数据残留（换目录或清空） |
| 中文乱码 | 库已 utf8mb4；CSV 导出自带 BOM，Excel 直接打开正常 |
| 爬虫定时没跑 | 定西每周一 09:00、平凉红牛每月 1 日 09:00（容器时区 Asia/Shanghai） |
| 想看示例数据 | 前端勾"包含示例数据"（is_sample=1 仅展示用，不参与默认统计） |
| 部署后图表空 | 确认后端已连库：`docker logs gl_backend | grep -i error` |
