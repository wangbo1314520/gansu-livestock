## 2. 核心表：price_data

| 字段 | 类型 | 说明 |
|---|---|---|
| id | BIGINT PK | 记录ID |
| region_id | INT FK→region | 地区 |
| breed_id | INT FK→breed, NULL | 品种（饲料类为 NULL） |
| category_id | INT FK→price_category | 价格分类 |
| price | DECIMAL(10,2) | 价格（元/斤） |
| unit | VARCHAR(20) | 计价单位，默认 元/斤 |
| source | VARCHAR(50) | gov政府 / manual手工 / dealer贩子 / market市场 / self自家 |
| source_detail | VARCHAR(100) | 来源明细（单位+期数） |
| record_date | DATE | 价格所属日期 |
| user_id / farm_id | INT | 录入人 / 牧场（自家数据） |
| created_at / updated_at | DATETIME | 创建/更新时间 |

索引：`idx_region_date(region_id, record_date)`、`idx_category_date(category_id, record_date)`、`idx_source(source)`、`idx_record_date(record_date)`

## 3. 预测与预警

**predict_result**：category_id + region_id + model 联合索引；
每模型每次预测逐日落一行（predict_date、predict_value、95% 置信上下界），
精度指标（mae/rmse/mape）记录在本次预测的行上。

**alert_rule.rule_type 五种规则**：

| 类型 | 含义 | 关键参数 |
|---|---|---|
| below_cost | 价格跌破阈值（成本线） | threshold |
| above_price | 价格高于阈值 | threshold |
| continuous_rise | 连续 N 天上涨 | continuous_days |
| continuous_fall | 连续 N 天下跌 | continuous_days |
| feed_rise | 饲料近期涨幅超阈值 | threshold（涨幅元/斤） |

巡检约束：同一规则同一天最多触发一条记录（去重）。

## 4. 家用版成本计算相关

**cost_config.feed_detail**（JSON）示例：

```json
{"玉米": 0.6, "豆粕": 0.2, "麸皮": 0.1, "苜蓿草": 0.1}
```

配合 `daily_feed_amount`（kg/天）与最新饲料价（元/斤×2=元/kg）计算日饲料成本；
每次保存新增一行（保留参数历史）。

**feed_stock 出入库约束**：出库数量不得超过当前库存（service 层校验），
出入库同时写 feed_record 流水。

## 5. 初始数据（init_data.sql）

- region：15 行（id=1 甘肃省 level=1；id=2..15 为 14 市州，parent_id=1，含行政区划代码）
- price_category：8 行（id 1-4 牲畜，5-8 饲料）
- breed：10 行（id 1-5 牛，6-10 羊，含产地备注）
- user：admin 账号（密码 admin123，bcrypt 哈希，**首次登录后必须改密**）

## 6. 维护要点

- 建表顺序即外键依赖顺序；如需重建，先 `SET FOREIGN_KEY_CHECKS=0` 或按逆序删表
- 时间字段统一 `DEFAULT CURRENT_TIMESTAMP`，updated_at 带 `ON UPDATE`
- 备份：APScheduler 周日 02:00 mysqldump 至 `data/backup/`（命令接入前为 TODO）
