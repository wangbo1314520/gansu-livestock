## 👀 每天看一眼（一分钟）

1. **首页四个大数字**：活牛、活羊、玉米、豆粕的价格
2. **红色 = 涨，绿色 = 跌**（小字"较上期"旁边）
3. 顶部**黄色提醒条**亮了 → 点进去看，然后联系儿子
