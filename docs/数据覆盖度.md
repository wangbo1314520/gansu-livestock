## 反推数据（derived，40 条）

- **用途**：补全活牛/活羊序列，使预测模型（ARIMAX 要求 ≥30 条）可用；**不用于统计报表**，与 gov 真实观测以 source 字段严格区分（前端以灰色"反推"标签+虚线展示）
- **方法**：定西同日重叠周的 活畜价/肉价 实测平均比值作系数，乘以缺失周的肉价
- **系数**：
  - 活牛/牛肉 = **0.3822**（12 个重叠周全量均值 0.3888，剔除 10-10 口径混搭周后取 0.38；
    首批 40 条按 0.39 入库，差异 <3% 在周度波动内，不追溯）
  - 活羊/羊肉 = **0.4224**（10 个重叠周，0.4147~0.4436，采用 0.42）
- **明细**：活牛补 19 条（13 gov + 19 derived = 32 周）、活羊补 21 条（11 + 21 = 32 周）
- **标记**：source='derived'，source_detail 与 remark 注明"由牛肉/羊肉价反推，系数X.XX"
  （首批按 0.39/0.42，后续重跑按 0.38/0.42）
- **验证**：反推后 ARIMAX 活牛预测跑通，MAPE 0.75%（优秀）
- 脚本：`backend/scripts/derive_livestock_price.py`（幂等，可重复执行）
