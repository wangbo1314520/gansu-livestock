## 第1章 绪论

### 1.1 研究背景

甘肃是全国重要的牛羊产业省份，肉牛存栏量常年位居全国前列，平凉红牛、甘南牦牛、
肃南甘肃高山细毛羊等特色品种在国内外市场具有较高知名度。以定西、平凉为代表的
陇东地区，家庭牧场（养殖规模为数十头牛、数百只羊）是最普遍的生产单元。这类家庭
牧场的市场决策长期依赖贩子口头报价和个人经验：活牛出栏时机的选择、饲料囤积的
时机、补栏还是压栏，往往"凭感觉"，价格波动带来的利润侵蚀显著。

政府价格监测体系（农业农村部"全国畜产品和饲料集贸市场价格"周报体系、各市州
畜牧兽医局周报、新华·中国平凉红牛价格指数等）实际上已形成稳定的数据发布渠道，
但这些数据散落在各政府网站与媒体转载页中，格式不统一、口径不统一（全国口径、
主产省份口径、本地口径并存），普通养殖户既没有渠道获取，也没有能力加工。

本文设计并实现一个面向甘肃家庭牧场的价格统计预测与趋势分析平台，把分散的政府
监测数据自动采集、统一口径入库，在此之上提供统计分析、ARIMAX 价格预测、价格
预警、成本与出栏建议等能力，并以"学校版（数据分析）+ 家用版（养殖决策）"双前端
适配两类用户。

### 1.2 研究意义

对家庭牧场而言，本平台将"凭经验"的决策过程数据化：（1）价格透明——聚合政府
周报与指数数据，养殖户可随时查看活牛、活羊与饲料的最新真实价格；（2）风险预警
——价格跌破成本线时主动提醒，避免"越养越亏"；（3）决策辅助——基于时间序列
预测给出出栏/压栏建议与压栏利润测算。对区域产业研究而言，平台沉淀的多源价格
数据库（真实观测 + 口径标注 + 反推补全）可作为后续研究的底座。

### 1.3 国内外研究现状

**农产品价格监测方面**，农业农村部自 2008 年起运行"全国农产品批发价格信息系统"，
按周发布 500 个县集贸市场的畜产品与饲料价格；新华指数（中国经济信息社）与地方
政府联合发布了"新华·中国平凉红牛价格指数"（月更，含活牛指数、S 级胴体、牛脑髓
三个分项），为特色畜种提供了市场化定价参考【文献1】【文献2】。这些体系的数据
质量高但分散，缺少面向小规模养殖户的整合出口。

**价格预测方法方面**，时间序列模型在农产品短期价格预测中应用最为成熟。经典
ARIMA 模型（Box-Jenkins 方法）适用于单变量平稳化后序列【文献3】；含外生变量的
ARIMAX/SARIMAX 可引入饲料成本等解释变量，在畜禽价格预测中普遍优于纯自回归
模型【文献4】【文献5】。近年来 LSTM 等深度学习方法在长序列上表现较好，但对
数据量要求高（通常需数百点以上），而地市级畜产品周价格序列通常仅数十点，传统
统计模型反而更为适用【文献6】。

**农业信息化系统方面**，国内已有面向规模化牧场的养殖管理系统（耳标、物联网、
饲喂自动化），但"价格监测 + 预测 + 预警 + 家庭账本"一体化、且以真实政府数据为
底座的轻量系统较少见【文献7】。

### 1.4 研究内容与论文结构

本文工作包括：（1）数据层——对 14 个候选数据源逐一侦察验证，落地定西市畜牧
兽医局周报、平凉市畜牧兽医局周报、新华·平凉红牛指数三个真实数据源爬虫，建立
带 is_sample/source 双标记的价格数据库；（2）分析层——ARIMA/ARIMAX 预测、
活畜价格反推补全、预警规则引擎；（3）应用层——学校版与家用版双前端。论文共
七章：第2章相关技术、第3章需求分析、第4章系统设计、第5章关键技术与实现、
第6章系统测试、第7章总结与展望。

【素材位置】产业数据引自数据源地图（docs/数据源地图.md）；三源爬虫入库实测
数据见 docs/数据覆盖度.md。

## 第2章 相关技术

### 2.1 后端技术：Flask 与 SQLAlchemy

后端采用 Flask 3.1 轻量框架，以蓝图（Blueprint）组织 12 个功能模块共 62 条
RESTful 路由，避免单文件膨胀。数据访问层使用 SQLAlchemy 2.1 ORM（声明式模型
+ Session 上下文管理），配合 PyMySQL 驱动连接 MySQL 8.0（utf8mb4 字符集）。
认证采用 PyJWT 无状态令牌 + bcrypt 密码哈希，装饰器 login_required /
role_required 实现路由级鉴权。相比 Django 的全家桶式结构，Flask 的微内核
特性与本系统"模块边界清晰、部署轻量"的诉求更匹配。

### 2.2 前端技术：Vue3 与 ECharts

前端采用 Vue 3 组合式 API（script setup）开发两套界面：学校版基于 Element Plus
桌面组件库，家用版基于 Vant 移动端组件库，构建工具均为 Vite。可视化统一使用
ECharts：趋势图实现多数据源分色系列（政府监测实线、反推补全灰色虚线、指数
绿色点线），预测图通过双序列堆叠面积实现 95% 置信区间带。

### 2.3 数据库：MySQL 8.0

数据库共 17 张表，核心表 price_data 采用"单表多口径"设计：region_id（14 市州
+省级）、category_id（8 价格分类）、source（gov 政府监测 / derived 反推 / index
指数 / dealer 贩子报价 / manual 手工 / self 自家）、is_sample（示例数据标记）
四个维度刻画每条价格记录，统计与展示按维度过滤。该设计使不同来源、不同可信度
的数据共存且互不污染。

### 2.4 时间序列预测：ARIMA 与 ARIMAX

ARIMA(p,d,q) 通过差分与自回归移动平均刻画单变量序列；ARIMAX 在此基础上引入
外生变量 X。本系统对"活畜价格—饲料价格"建模：以玉米价格作为外生变量的
SARIMAX 模型捕捉饲料成本对活牛价格的传导。平稳性以 ADF 检验判断，阶数按 AIC
准则网格搜索确定。评价指标采用留出法回测的 MAE / RMSE / MAPE，MAPE<10% 视为
优秀。

### 2.5 数据采集：Requests 与 BeautifulSoup

爬虫基于 requests + BeautifulSoup4 + 正则表达式实现，不依赖浏览器内核。针对
政府站群的两类发布形态分别设计：定西站（大汉版通 CMS）通过其 dataproxy.jsp
数据接口直接获取 XML 文章列表；平凉红牛指数月报通过东方财富文章搜索接口
定位转载页 URL 后抓取正文。采集遵守 3 秒请求间隔与研究性 UA 标识。

## 第3章 需求分析

### 3.1 用户需求分析

系统面向两类用户。**分析型用户**（农经研究者、学校师生）需要多地区多分类的
价格查询、趋势对比、同比环比分析、预测精度评估。**生产型用户**（家庭牧场主，
典型规模为 50 头黄牛繁殖+育肥、500 只母羊及羊羔）的核心诉求来自真实生产决策：
"现在活牛什么价""跌破我成本线了没有""现在卖还是再养一个月""这头牛到现在
一共花了多少钱"。后者不熟悉专业术语，需要大字、少层级、说人话的移动端界面。

### 3.2 功能需求（五大模块）

（1）**价格数据中心**：多源采集入库、统一元/斤口径、示例数据隔离；（2）**统计
分析**：最新价、趋势、地区对比、同比环比、数据导出（CSV）；（3）**预测**：
ARIMA/ARIMAX 双模型、置信区间、回测精度；（4）**预警**：跌破成本线/涨超阈值/
连续涨跌三类规则，触发记录与已读管理；（5）**家庭经营**：成本计算器、压栏对比、
出栏建议、存栏管理、饲料库存、家庭账本八步流程。

### 3.3 非功能需求

性能：常规查询接口 <200ms，预测接口首跑 <15s；安全：JWT 鉴权、密码 bcrypt
哈希、示例数据与真实数据默认隔离；易用性：家用版首页一屏呈现四个核心价格，
配合 375px 手机宽度适配；可维护性：爬虫幂等可重跑、双标记数据体系、28 项自动化
测试。

### 3.4 可行性分析

数据可行性：经 14 源侦察验证，定西/平凉两政府源零反爬可稳定抓取，红牛指数经
媒体转载页可达，数据基础成立。技术可行性：全部采用成熟开源栈，无算法黑盒。
经济可行性：开发与运行零软件成本（本机部署 + 局域网访问）。

## 第4章 系统设计

### 4.1 总体架构设计

系统采用三层架构：【图：docs/figures/fig5_architecture.mmd 渲染后为图4-1】
表现层（学校版 Element Plus / 家用版 Vant，Vite 构建静态资源，Nginx 式静态服务
+ /api 反代）；应用层（Flask 12 蓝图 62 路由：价格、饲料、预测、关联分析、
预警、成本、建议、牧场、账本、认证、基础数据、后台管理；APScheduler 承担
爬虫定时与预警巡检）；数据层（MySQL 17 表 + 三个爬虫数据源 + 示例数据）。

### 4.2 功能模块设计

价格模块为核心枢纽：latest（地区兜底降级）、trend（动态回退 + 逐点来源标记）、
compare/yoy、export（CSV+BOM）。预测模块产出 history/forecast/metrics/adf
四段结构，落库 predict_result 供精度追踪。预警模块规则引擎支持 below_cost、
above_price、continuous_rise、continuous_fall 四类规则。家庭经营模块以
牧场（farm）为聚合根联动存栏、饲料库存与账本。

### 4.3 数据库设计

17 表 E-R：【截图：docs/screenshots/db_schema.md 的 mermaid ER 图，定稿渲染为
图4-2】。核心设计三点：（1）price_data 的 source × is_sample 双标记体系——
真实观测（gov/index）、衍生数据（derived）、示例数据（manual=示例）严格区分，
默认查询仅真实数据；（2）breed 表以 (name, stage) 复合唯一支持"黄牛-育肥牛"
类细分（21 条细分记录，覆盖 bull/cow/calf/fattening/ram/ewe/lamb 七阶段）；
（3）livestock 一头一记录 + status 枚举（raising/sold/dead），阶段信息由
breed_id 表达。

### 4.4 接口设计

62 条路由按 12 模块分组（【表：docs/论文数据统计.md 表4】）。关键约定：列表类
接口返回分页结构 {list, total, page}；趋势类返回 {points, data_region_id,
data_region_name, fallback}，当请求地区无数据时动态回退并显式告知实际数据源
地区；家用版功能（成本/建议/牧场/账本）受 APP_MODE 开关保护。

## 第5章 关键技术与实现

### 5.1 数据采集与清洗

定西爬虫破解大汉版通 CMS 的 dataproxy.jsp 列表接口（columnid=8319 共 229 条
记录），对 191 篇价格类文章逐篇解析，双模式正则适配"部级转载句式"（主产省份
活牛价格 X 元/公斤）与"本地季报句式"（活牛全市均价 X 元/公斤），全角转半角
后提取，元/公斤统一除以 2 换算为元/斤。最终入库 148 条真实周报数据，覆盖
2024-06 至 2026-10 共 32 个周报日期。平凉红牛指数爬虫经东方财富搜索接口定位
月报转载页，提取活牛指数与单价、S 级胴体价。采集全程 3 秒间隔、幂等入库
（重复执行零新增）。

### 5.2 活畜价格反推方法

问题：部级周报并非每周发布活牛/活羊价格（32 个周中仅 13/11 周有），序列长度
不满足预测门槛（≥30）。方法：以同日重叠周的"活畜价/肉价"实测比值作系数，
乘以缺失周肉价反推。系数核实（【表：docs/反推系数核实.md 配对明细】）：活牛/
牛肉剔除口径混搭周后均值 0.3822（11 周，σ=0.0102），活羊/羊肉 0.4201（9 周，
σ=0.0033）；外部旁证（农业农村部主产省活牛 28.76 ÷ 全国牛肉 74.41 = 0.3865）
与行业常识（活畜价约为肉价四折）双重印证。反推数据以 source='derived' 标记，
前端灰色标签+虚线区分，仅用于预测补全，不参与统计报表。反推后活牛序列补齐至
32 周，ARIMAX 预测得以运行。

### 5.3 ARIMAX 预测模型

预处理链：日历插值（周度数据转日度）→ 缺失值 bfill/ffill → ADF 平稳性检验
→ 一阶差分。模型以玉米价格为外生变量，AIC 网格搜索定阶（典型 (1,1,1)），
输出 30 天逐日预测与 95% 置信区间。回测采用最近留出法，test_days 与预测步长
一致（本实现中曾因二者不一致引发数组形状错误，修复后任意步长稳定）。实测
精度（真实+反推数据）：活牛 MAPE 0.75%（优秀）、牛肉 MAPE 0.96%（优秀），
均显著优于 10% 的优秀线。【图：docs/figures/fig3_cattle_forecast.png 为图5-1】

### 5.4 预警规则引擎

四类规则（跌破成本线/涨超阈值/连续上涨/连续下跌）每小时整点巡检，命中即写
alert_record（含触发值与人话 message）。实测：规则"活牛跌破 16 元"在当前价
15.15 元下正确触发并落库，"跌破 14 元""玉米涨超 1.2"（现价 1.17）正确不触发。

### 5.5 前端可视化

学校版趋势图四色数据源系列 + 图例切换 + 悬停来源说明；Dashboard 核心四卡
（活牛/活羊/玉米/豆粕）带环比与来源标签；预测图置信带与虚线预测段。家用版
价格卡 30px 大字、较上期涨跌（红涨绿跌）、右下来源角标。响应式 375/768/1366
三档宽度验证通过。【截图：docs/screenshots/school_02_dashboard.png、
home_01_home.png、resp_*.png】

## 第6章 系统测试

### 6.1 功能测试

pytest 自动化测试 28 项全部通过，覆盖认证（不存在用户/错误密码不泄露信息）、
价格接口（默认排除示例、trend v2 结构、CSV 导出 BOM 与表头）、预警触发逻辑、
反推数据标记（source/is_sample/remark 三重约束 + gov/derived 同日不重复）。
【表：测试清单 backend/tests/ 目录，28 项结果 6.4 节汇总】

### 6.2 性能测试

本机实测（MySQL 本地、Flask 单进程）：认证接口约 30ms，latest/trend 等
查询接口 50~200ms（首次连接含 SQLAlchemy 引导），预测接口首跑约 8~15s
（statsmodels 冷启动），其后同进程 3s 内。CSV 导出 4000+ 行 <1s。满足家用
与教学场景。

### 6.3 数据质量测试

一致性：按 source × is_sample 分组统计与入库日志一致（gov 184 / derived 40 /
index 4 / 示例 3952）。合理性抽检：随机 10 条（种子 42）价格区间核对——玉米
2.4~2.5 元/公斤、豆粕 3.3~3.4、牛肉 68~76、羊肉 71，全部落在全国行情区间；
反推值（牛肉 32.85 × 0.39 ≈ 12.8 元/斤）落在活牛真实观测区间（11.6~15.2）
内。【表：docs/数据覆盖度.md 抽检节】

### 6.4 用户试用反馈

家用版八步流程（登录-看价-查趋势-算成本-看建议-设预警-记账-查账本）以真实
数据走通；出栏建议"可继续观察"的压栏测算经手工验算一致（收入差 1285.2 −
追加成本 695.7 = 净差 +589.5 元/头）。试用中发现的三处易用性问题（批量录入、
状态字段语义、接口参数兼容）已在本轮修复并复验。

## 第7章 总结与展望

### 7.1 工作总结

本文完成了从数据到决策的全链路：三个真实政府/指数数据源落地（188 条真实
数据 + 40 条标注反推）、62 路由分析后端、双前端、预测（MAPE<1%）、预警与
家庭经营模块，并以生产模式在局域网部署供家庭实际使用。

### 7.2 创新点

（1）**双标记数据体系**：source × is_sample 让多来源多可信度数据共存且默认
隔离；（2）**活畜价格反推补全**：以实测系数（经内部稳定性、外部旁证、行业
常识三重验证）填补源站发布缺口，使短序列可预测，且反推数据全程可辨识；
（3）**轻量双端适配**：同一后端以模式开关服务分析型与生产型两类用户。

### 7.3 不足与展望

数据方面：目前真实源以定西/平凉为主，牦牛、藏羊细分价格尚无政府口径来源
（青海指数待评估）；省级站群 WAF 限制了大范围采集。模型方面：可引入季节性
更强的 SARIMA 周期项与多变量模型对比；预测区间校准（coverage 检验）有待补充。
功能方面：Excel 报价一键导入、移动端推送、多用户权限细分是下一步重点。
