## 家用版实测发现的问题（阶段4，记录于 error.log）

1. **cost/calculate 曾 500"缺少麸皮价格"**（真实源仅玉米/豆粕，示例数据时代掩盖）——已修复：
   缺项回退不限地区+含示例的最新价。修复后全指标验算通过：revenue 13635（450×2×15.15）✓
   profit 4635 ✓ breakeven 10.0 元/斤 ✓ daily_feed_cost 20.19（8kg×2×加权价 1.262，kg/斤换算正确）✓
2. **接口签名与任务假设不符**：cost 需 total_cost（非 daily_gain/feed_detail 直传）；advice/sell 需
   current_price+total_cost+predicted_price（非自动查库）。仅记录未改
3. **livestock/add 无 count 批量支持**：20 只羊只落 1 条（一头一记录设计），批量场景需循环调用
4. **status 无枚举校验**：误传 fattening/ewe 入库后不入 raising 统计（应 breed_id 表阶段、status 只用
   raising/sold/dead）；测试数据已修正复验（cattle 4/sheep 1 统计正确）
- advice 建议合理性：action=wait"可继续观察"——压栏 30 天净差 +589.5 元
  （收入差 1285.2 − 追加成本 695.7，数学自洽）✓；账本汇总 net_profit 26600 与记录一致 ✓
