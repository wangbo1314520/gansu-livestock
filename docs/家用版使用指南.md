# 家用版使用指南（给爸妈看的大白话版）

> 打印这一份就够了。手机上打不开、看不懂的地方，直接问儿子。
> 配图在文末，对应手机上的实际样子。

---

## 一、怎么打开

1. 手机连上**家里的 WiFi**（和电脑主机连同一个）
2. 打开手机浏览器（Chrome、夸克、微信里的浏览器都行）
3. 在地址栏输入：

   **http://172.16.15.179:8081**

   （嫌每次输入麻烦：打开后点浏览器菜单里的"添加到主屏幕"，以后点图标就能进）
4. 输入账号密码登录（账号：____________ 密码：____________）

> 注意：电脑主机得开着，这个网址才能打开。主机一关，手机上就打不开了。
> 如果换地方住了或者路由器变了，网址里的数字可能会变，变了就问儿子。

---

## 二、首页看什么

打开后第一屏就是四个大字价格卡：**活牛、活羊、玉米、豆粕**。

- 大数字就是**现在的价格**，单位是"元/斤"
- 数字下面有一行小字"较上期 ±X%"：
  - **红色 = 涨了**
  - **绿色 = 跌了**
- 小卡片右下角有个小标签：
  - 绿标签"政府"= 政府周报的真实价格（最可靠）
  - 灰标签"反推"= 系统按牛肉价推算的（参考用）
  - 黄标签"示例"= 演示数据（不作数）
- 页面顶部如果有**黄色提醒条**，说明价格触发了预警（比如跌破成本线），一定要点进去看

## 三、怎么算利润

想知道一头牛现在卖能赚多少：

1. 首页点 **🧮 成本计算器**
2. 填三个数：
   - **体重**：这头牛大概多少公斤（比如 450）
   - **当前价**：首页活牛的价格（比如 15.15）
   - **总成本**：这头牛从买来到现在一共花了多少钱（饲料+药+本钱）
3. 点计算，系统给出：
   - **利润**：卖一头能赚（亏）多少钱
   - **保本价**：价格低于这个数就亏本
   - **每天饲料钱**：一天要喂掉多少

（对应配图③）

## 四、怎么看"现在能不能卖"

1. 首页点 **💡 出栏建议**
2. 输入体重和成本（跟计算器一样）
3. 系统会给出四种说法之一：
   - **建议出栏**：现在价格好，往后要跌，趁早卖
   - **可压栏**：现在卖亏钱，预测要回暖，再养养
   - **尽快出栏止损**：越养越亏，长痛不如短痛
   - **可继续观察**：还有上涨空间，不着急
4. 每条建议后面都跟着一句人话解释，照着做就行

（对应配图④）

## 五、怎么记账

卖了牛羊、买了饲料，都记一笔，年底算账心里有数：

1. 首页点 **📒 家庭账本**
2. 卖了牛羊：记**收入**（金额 = 数量 × 每只总价，或直接填总价）
3. 买了饲料、疫苗、草料：记**支出**
4. 账本会自动算出**今年净赚多少**

家里有牛羊数量变化（买了、卖了、生了、死了），顺手在 **🐄 存栏记录** 里改一下，
这样首页下面的统计才准。

（对应配图⑤）

## 六、遇到问题怎么办

| 问题 | 先自己试 | 还不行 |
|------|---------|--------|
| 网址打不开 | ①看电脑主机开没开 ②看 WiFi 连没连对 ③把网址重新输一遍 | 问儿子 |
| 要登录/掉线了 | 重新输一遍账号密码 | 问儿子要账号 |
| 价格好多天没变 | 正常，政府周报一周更新一次 | 超过两周没变问儿子 |
| 数字看着不对劲 | 看小标签是不是"示例"（示例不作数） | 截图发给儿子 |
| 手机上字太小 | 浏览器菜单里放大/双击屏幕 | — |

**记住一句话：拿不准的时候，截图发儿子。**
