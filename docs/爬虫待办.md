# 爬虫待办（2026-10-10 实测结论）

## 已落地的数据源

### ✅ 张掖市畜牧兽医局价格周报（可用，已实测）
- 入口：`http://www.zhangye.gov.cn/xmj/dzdt/tzgg/index.html`（通知公告列表，翻页 `index_1.html`）
- 周报正文为纯文本，`ZhangyeSpider`（spider/gov_spider.py）已实现 发现→抓取→解析 全管道
- 试抓 3 期 × 3 条 = 9 条记录，样本见 `data/spider_sample_20261010.json`
- robots.txt 不存在（404，无限制）；请求间隔 3 秒
- 运行：`backend\venv\Scripts\python.exe spider\gov_spider.py zhangye`

## 需要人工决策的事项

1. **猪价分类问题**：张掖周报只发布猪价（生猪/仔猪/白条猪），与项目现有 8 分类
   （活牛/牛肉/活羊/羊肉/4饲料）不重合。二选一：
   - a) `price_category` 增加 `生猪`（livestock）、`仔猪`、`白条猪`（猪肉）三个分类，
      周报数据即可入库（约改 1 行 SQL + init_data 追加 3 行）
   - b) 项目只做牛羊，猪价仅作行情参考不入库
2. **周报日期口径**：三篇周报页面"日期"同为发布日（集中补发），真实周次在
   `source_detail` 的"第N周"里。如需按周入库，要在 clean 层把周次换算为该周周一日期。

## 后续扩展建议
